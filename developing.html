Developing Process


Alpha version
In alpha version we had only materials that was needed to crreate a pad. We had: base pad, buttons, wires, Arduino Leonardo, glue, foil, papers and scissors.


Beta version
In beta version, we had functionally buttons and working pad. Wires that connects pad and Arduino was very short and were constantly breaking away from each other.

Final version
In final version we will add colorful arrows on buttons and hide arduino in box. Also, we wil try to find long wire to connect Arduino with computer.
